# 极简时钟 · 复古指针版

一台由 HTML 和 CSS 绘制的传统双铃闹钟：黑色外壳、暖白表盘与指针显示本地时间，表盘下方显示日期和星期。透明窗口适合摆放在桌面上。

## 能力

使用 `widget.ui` 渲染界面，使用 `widget.chrome` 隐藏宿主顶栏并控制自己的窗口；不联网，也不读取或保存宿主状态。时钟从设备的本地时间更新，秒针每秒走动；屏幕阅读器可读取完整时间和日期。

## 操作

- 按住闹钟本体拖动窗口。
- 鼠标移入窗口时，顶部居中显示缩小、放大和关闭按钮；按钮也可用键盘操作。
- 缩小和放大可在 320×300、340×350、400×420、460×500、540×600 五档之间调整窗口，闹钟随窗口缩放。宿主以清单中的最大尺寸作为默认尺寸和宽度上限。
- 需要在 Lull 中授予窗口控制权限；未授权时宿主会显示顶栏。
- 时钟页面不支持文本框选，也不显示浏览器默认右键菜单。

## 实现

- 表壳、双铃、刻度和指针均使用 HTML 与 CSS 绘制，无外部素材或字体。
- 通过定时器在每秒边界更新时间。
- 使用随包附带的 Lull Widget SDK 控制拖拽、窗口大小和关闭；SDK 采用 Apache-2.0，许可原文见包内 `SDK-LICENSE.txt`。

## 安装

下载 `.zip` → Lull **设置 → 扩展 → 从文件安装** → 启用并打开。

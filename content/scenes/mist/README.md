# 雾岚 · Mist

薄雾漫过层叠青山和湖面。远处的山脊、柔光、近岸松影与细微水纹让画面更有深度；移动鼠标时，一片柔和雾光会跟随。

- 在 Lull 的壁纸设置中可调整**氛围强度**和关闭**鼠标响应**。
- 鼠标位置由 Lull 场景宿主提供；壁纸不接收点击、按键或滚轮，桌面操作保持正常。
- 支持系统及 Lull 的减少动态效果设置；壁纸隐藏时暂停动画。无外部网络资源。
- 脚本场景需 Lull 场景宿主 API 3 或更新版本，运行在隔离的 iframe 中。

## 安装

下载 `.zip` → Lull **设置 → 扩展 → 从文件安装** → **壁纸 → 场景** 选择「雾岚」。

## 来源与许可

基于 Lull 官方「雾岚」社区场景深化制作，以 CC BY 4.0 提供。原始 1.0 场景保存在 `test/fixtures/mist-v1/`，用于摘要算法自检。

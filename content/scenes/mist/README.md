# 雾岚 · Mist

薄雾漫过远山的极简夜景。低饱和的青灰色调，几乎不抢注意力，适合长时间留在桌面上。

## 特点

- **纯静态**：只有 HTML 与 CSS，运行在 `sandbox=""` 的 iframe 里，不执行任何脚本。
- **低功耗**：`performance.tier` 为 `low`，目标 30fps，动画只有一层缓慢的雾气位移。
- **自适应**：所有尺寸用视口单位计算，多显示器分辨率不一致也不会拉伸变形。

## 安装

下载下方的 `.zip`，在 Lull 里打开 **设置 → 扩展 → 从文件安装**，选择该文件即可。
安装后到 **壁纸 → 场景** 里选择「雾岚」。
